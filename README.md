# Java-CF-DataStructs

This repository contains practical implementations and demonstrations of core Java Data Structures and the Java Collections Framework (CF).

The code in this repository follows along with the excellent [Java Data Structures Tutorial](https://www.youtube.com/watch?v=8MmMm2-kJV8) (Focused on 1D & 2D Arrays, Lists, Set and Maps) created by [Amigoscode](https://www.youtube.com/@amigoscode).

## Table of Contents & File Reference

Below is the chapter-by-chapter breakdown of the concepts covered, linking directly to the video timestamps and the corresponding source code files in this repository.

### Chp 1: [Arrays](https://youtu.be/8MmMm2-kJV8?si=m4t_539NXbp1wWHm&t=206)
* **File:** [`Array1D.java`](Array1D.java)
* **Concepts:** 1D array initialization, assignment, and traversal.

### Chp 2: [2D Arrays](https://www.youtube.com/watch?v=8MmMm2-kJV8&t=1057s)
* **File:** [`Array2D.java`](Array2D.java)
* **Concepts:** Multi-dimensional arrays and matrix representation.

### Chp 3: [Lists and ArrayList](https://www.youtube.com/watch?v=8MmMm2-kJV8&t=1504s)
* **File:** [`ListNArrayList.java`](ListNArrayList.java)
* **Concepts:** The `List` interface, dynamic arrays, and standard CRUD operations.

### Chp 4: [Stack](https://www.youtube.com/watch?v=8MmMm2-kJV8&t=2232s)
* **Files:** [`StackDemo.java`](StackDemo.java), [`ListRefStackObj.java`](ListRefStackObj.java)
* **Concepts:** LIFO (Last-In-First-Out) structures, `push()`, `pop()`, `peek()`, and polymorphism/downcasting.

### Chp 5: [Queue](https://www.youtube.com/watch?v=8MmMm2-kJV8&t=2776s)
* **File:** [`QueueDemo.java`](QueueDemo.java)
* **Concepts:** FIFO (First-In-First-Out) structures and standard queue operations.

### Chp 6: [Linked List](https://www.youtube.com/watch?v=8MmMm2-kJV8&t=3246s)
* **File:** [`LinkedListDemo.java`](LinkedListDemo.java)
* **Concepts:** Nodes, doubly-linked lists, and implementing both `List` and `Deque` interfaces.

### Chp 7: [Sets](https://www.youtube.com/watch?v=8MmMm2-kJV8&t=4025s)
* **File:** [`HashSetDemo.java`](HashSetDemo.java)
* **Concepts:** Uniqueness, `HashSet`, and preventing duplicate entries.

### Chp 8: [Map Interface](https://youtu.be/8MmMm2-kJV8?t=4563&si=2MO218rKB669z2vP)
* **Reference:** [`map_interface_n_implemented_classes.png`](map_interface_n_implemented_classes.png)
* **Concepts:** Understanding the hierarchy of the Map interface.

### Chp 9: [Map](https://youtu.be/8MmMm2-kJV8?t=4686&si=m1R2Wl8Mocixbpz5)
* **File:** [`HashMapDemo.java`](HashMapDemo.java)
* **Concepts:** Key-Value pair storage, retrieval, and preventing key duplication.

### Chp 10: [Hash Functions and HashCode](https://youtu.be/8MmMm2-kJV8?t=5279&si=cyoube3Yc1azCwbr)
* **File:** [`HashCodeDemo.java`](HashCodeDemo.java)
* **Concepts:** How hash functions work, memory buckets, and overriding `hashCode()` and `equals()`.
